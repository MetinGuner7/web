📖 Mutlak Değer Nedir?

Bir sayının mutlak değeri, o sayının sayı doğrusunda sıfıra olan uzaklığıdır. Uzaklık her zaman pozitif veya sıfır olduğu için mutlak değer asla negatif olamaz.

Mutlak Değer Tanımı
$$|x| = \begin{cases} x & \text{eğer } x \geq 0 \\ -x & \text{eğer } x < 0 \end{cases}$$
$|5| = 5$
$|-5| = 5$
$|0| = 0$
$|-\pi| = \pi$
💡
Geometrik Yorum: $|a - b|$ ifadesi, a ile b arasındaki uzaklığı verir. Örneğin: $|7 - 3| = |3 - 7| = 4$

📐 Mutlak Değer Özellikleri

1
Pozitiflik
Mutlak değer her zaman sıfır veya pozitiftir.
$|x| \geq 0$ (her x için)
2
Simetri
Bir sayının ve zıt işaretlisinin mutlak değeri aynıdır.
$|x| = |-x|$
3
Çarpımın Mutlak Değeri
Çarpımın mutlak değeri, mutlak değerlerin çarpımına eşittir.
$|x \cdot y| = |x| \cdot |y|$
4
Bölümün Mutlak Değeri
Bölümün mutlak değeri, mutlak değerlerin bölümüne eşittir.
$\left|\frac{x}{y}\right| = \frac{|x|}{|y|}$ (y ≠ 0)
5
Üçgen Eşitsizliği
Toplamın mutlak değeri, mutlak değerlerin toplamından küçük veya eşittir.
$|x + y| \leq |x| + |y|$
Önemli Eşitlik
$$|x|^2 = x^2 \quad \text{ve} \quad \sqrt{x^2} = |x|$$

⚖️ Mutlak Değerli Denklemler

|f(x)| = a biçimindeki denklemlerin çözümü için durum analizi yapılır.

✓
$|x| = a$ (a > 0)
İki çözüm vardır
$x = a$ veya $x = -a$
●
$|x| = 0$
Tek çözüm
$x = 0$
✗
$|x| = a$ (a < 0)
Çözüm yok
Boş küme
1
Örnek: $|2x - 3| = 5$
İki durum için çözelim:
Durum 1: $2x - 3 = 5$ → $x = 4$
Durum 2: $2x - 3 = -5$ → $x = -1$
🧠 Ezberle!
$|f(x)| = a$ → $f(x) = a$ veya $f(x) = -a$
$|f(x)| = |g(x)|$ → $f(x) = g(x)$ veya $f(x) = -g(x)$

📊 Mutlak Değerli Eşitsizlikler

Temel Eşitsizlik Kuralları (a > 0)
$$|x| < a \Leftrightarrow -a < x < a$$ $$|x| > a \Leftrightarrow x < -a \text{ veya } x > a$$
📊 Sayı Doğrusunda Gösterim
$|x| < 3$ → $(-3, 3)$
$|x| > 3$ → $(-\infty, -3) \cup (3, \infty)$
$|x| \leq 3$ → $[-3, 3]$
$|x| \geq 3$ → $(-\infty, -3] \cup [3, \infty)$
💡
Kolay Hatırlatma:
• "Küçüktür" (<) → Aralık (iç bölge)
• "Büyüktür" (>) → Birleşim (dış bölge)

🔄 İç İçe Mutlak Değer

İç içe mutlak değer ifadelerinde içten dışa doğru çözüm yapılır.

Örnek Çözüm
$$||x| - 3| = 2$$
1
Dış Mutlak Değeri Aç
$|x| - 3 = 2$ veya $|x| - 3 = -2$
$|x| = 5$ veya $|x| = 1$
2
İç Mutlak Değerleri Çöz
Her bir denklemi ayrı çöz:
$|x| = 5$ → $x = 5$ veya $x = -5$
$|x| = 1$ → $x = 1$ veya $x = -1$
3
Çözüm Kümesi
Tüm çözümleri birleştir:
$x \in \{-5, -1, 1, 5\}$

🎯 Örnek Sorular

Örnek 1 Kolay
$|3x - 6| = 9$ denkleminin çözüm kümesi nedir?
Çözümü Göster
Durum 1: $3x - 6 = 9$
$3x = 15$ → $x = 5$
Durum 2: $3x - 6 = -9$
$3x = -3$ → $x = -1$
Cevap: $x \in \{-1, 5\}$
Örnek 2 Orta
$|2x + 1| < 5$ eşitsizliğinin çözüm kümesi nedir?
Çözümü Göster
Adım 1: $|f(x)| < a$ → $-a < f(x) < a$ kuralı:
$-5 < 2x + 1 < 5$
Adım 2: Her taraftan 1 çıkaralım:
$-6 < 2x < 4$
Adım 3: Her tarafı 2'ye bölelim:
$-3 < x < 2$
Cevap: $x \in (-3, 2)$
Örnek 3 Zor
$|x - 2| + |x + 3| = 7$ denklemini sağlayan x'lerin toplamı kaçtır?
Çözümü Göster
Analiz: Kritik noktalar: $x = 2$ ve $x = -3$. Bu noktalar sayı doğrusunu 3 bölgeye ayırır.
Bölge 1 ($x < -3$): $-(x-2) + (-(x+3)) = 7$ → $-2x - 1 = 7$ → $x = -4$ ✓
Bölge 2 ($-3 \leq x < 2$): $-(x-2) + (x+3) = 7$ → $5 = 7$ → Çözüm yok
Bölge 3 ($x \geq 2$): $(x-2) + (x+3) = 7$ → $2x + 1 = 7$ → $x = 3$ ✓
Toplam: $(-4) + 3 = -1$
Cevap: -1
🔑 Anahtar Noktalar
  • $|x| \geq 0$ her zaman (mutlak değer negatif olamaz)
  • $|x| = a$ → $x = a$ veya $x = -a$ (a > 0 için)
  • $|x| < a$ → $-a < x < a$ (iç bölge)
  • $|x| > a$ → $x < -a$ veya $x > a$ (dış bölge)
  • $\sqrt{x^2} = |x|$ (karekökün mutlak değerle ilişkisi)
